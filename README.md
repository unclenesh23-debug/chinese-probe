# Проба iPhone

Проверочная страница перед новым приложением для китайского: 11 коротких шагов на iPhone (открытие, работа без сети, звук, микрофон, связь), в конце — кнопка «Скопировать отчёт».

Адрес: https://unclenesh23-debug.github.io/chinese-probe/

Исходник и сборка — в проекте (`app-pwa/probe-src/`, `python app-pwa/probe-src/build.py`); сюда кладётся готовое из `app-pwa/dist/probe/`.
